# HB 空調自動關機（v1.56.0）

Dashboard 空調卡的「自動關機」使用智能居家分頁既有的「自動關機小時數」整數欄位。
0／空白為停用；介面與 API 接受 0–168 整數小時，非法 Sheet 值保守視為停用。
不新增欄位或 HA 自動化，不恢復防黴／半度回饋；HA 組件不用更新。

## HA 空調計時規則

- HB 每 60 秒讀既有 HA 快照，確認 on 後建立一次計時；Dashboard、Apple Home、HA 開機都同樣適用。
- 第一次接手已開機的空調，或首次啟用此功能，從 HB 確認狀態時計時，不採用遷移前的舊開機時間。
- 改溫度、風速或在開機模式間切換，不延長期限。確認 off 後結束這一輪，下次 on 重新計時。
- 更改時數時，結束舊計時並從當下重新開始；離線時保存，恢復可用狀態後才開始新計時。相同時數保存不重置。
- 手動關機排程優先，包括待執行、待確認或執行失敗的手動 off。自動計時保留原期限、暫停送出；手動排程取消／移除後恢復原期限。
- 若解除手動優先時已過原期限，按既有排程規則評估：逾期 2 小時內可執行，超過 2 小時標為過期、不補送。
- 關機指令完成、失敗或結果未知後，本輪不重新下令；未知結果請先確認設備。明確停用後再次啟用才會建立新一輪。

HB 使用既有排程指令分頁保存計時；来源「自動（HA）」與舊「自動」分開。
參數 `_auto_hours` 保存本輪時數，`_auto_paused` 為手動優先，`_auto_closed` 表示本輪結束。
這些內部欄位不傳給 HA。未結束的列即使已執行也保留，防止 Render 重啟後把同一次開機重新排程。
確認關機或設定改變後，正常結果移至既有封存分頁，待確認／失敗仍保留供查看。
未結束的自動列不能用一般排程編輯／刪除；請在「自動關機」調整時數或停用。

## 執行與限制

計時與到期檢查都在 HB，需 Render 持續運行。HA 失聯／狀態不確定不視為關機，不重置計時也不發指令。
恢復後若仍 on，既有期限保留；已過期超過 2 小時不補送。HB／HA 離線期間或兩次檢查之間完成的短暫 off→on 無法重建。
本功能不是精確開機事件紀錄，也不能偵測直接用實體 IR 遙控器操作造成的狀態差異。
HA 的 SwitchBot Cloud 狀態仍是最後指令，不是冷氣真實電源回讀。

非 HA 空調維持既有 handler 的開機 transition 與自動排程機制；Dashboard 更改時數時重算，0 取消計時。
只有完整 HB API key 可存取 `/api/ac/auto-off`；Dashboard 需一般成員 session，kid／受限語音與橋接 key 不開放。

## 部署與還原

先部署 HB，再部署 Dashboard 1.56.0。原 Sheet 大於 0 的有效設定會重新生效；首次看到已開機從當下開始計時。
不修改家庭設定值或實際控制家電來測試；離線測試與 demo 覆蓋計時與 UI，實體到期反應由使用者驗收。
回復時先退 Dashboard 再退 HB；舊 HB 會拒絕／取消「自動（HA）」列。若日後再升級，需要確認本輪紀錄與設定，必要時先停用再啟用。
